# やんばる学生ハッカソン 2026 募集要項

※ この要項は、youkou-check の動作を見せるために作った**架空の大会**のものです。実在の大会・団体とは関係ありません。

## 1. 開催概要

やんばる学生ハッカソン 2026 は、地域の困りごとをソフトウェアで解決する、学生向けのオンライン・ハッカソンです。

- 開発期間：2026年11月1日（日）10:00 から 2026年11月3日（火・祝）18:00 まで（日本時間）
- 提出締切：2026年11月3日（火・祝）18:00（日本時間）。締切を過ぎた提出は、理由を問わず受け付けません。
- 開催形式：完全オンライン

## 2. 参加資格

- 2026年11月1日の時点で、大学・大学院・高等専門学校・専門学校に在籍している学生であること。
- 沖縄県内の学校に在籍しているか、沖縄県内に住んでいること。
- 18歳未満の方は、保護者の同意書を提出してください。
- チームは1名以上3名以下とします。1人での参加もできます。

## 3. 作品の条件

- 開発期間中に新しく作った作品に限ります。開発期間より前に書いたコードを含む作品は、審査の対象外とします。
- ただし、公開されているライブラリやフレームワークは使ってかまいません。
- 他人の著作物（画像・音楽・文章など）を使う場合は、利用が許諾されているものに限り、出典を README に書いてください。
- 実在する個人の情報（氏名・連絡先・顔写真など）を、本人の同意なく作品に含めてはいけません。

## 4. 提出物

次の4つをすべて提出してください。1つでも欠けている場合は、審査の対象外とします。

1. **GitHub リポジトリの URL**
   - リポジトリは公開（Public）にしてください。
   - README.md に、作品の説明、動かし方（必要なものと手順）、使った外部サービスを書いてください。
   - ライセンスのファイル（LICENSE）を置いてください。種類は問いません。
   - API キーやパスワードなどの秘密の情報を、リポジトリに含めないでください。
2. **デモ動画の URL**
   - 長さは2分以内とします。2分を超えた部分は審査しません。
   - YouTube の限定公開でもかまいません。
3. **作品の概要**（400字以内）
4. **代表者の連絡先**（メールアドレス）

## 5. 審査

| 観点 | 配点 |
|---|---|
| 地域の困りごとに合っているか | 40% |
| 実際に動くか | 30% |
| 工夫・技術 | 30% |

審査員は、提出されたリポジトリと動画を見て審査します。

## 6. 禁止事項

- 他の大会にすでに提出した作品を、そのまま提出すること。
- 生成 AI で作った文章や画像を、そう分かるように示さずに使うこと。生成 AI を使った場合は、どこに使ったかを README に書いてください。

## 7. 問い合わせ

問い合わせは、大会の Discord の #質問 チャンネルで受け付けます。
